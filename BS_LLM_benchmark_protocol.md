# BrainSafe AI vs general-purpose LLMs — head-to-head benchmark protocol

**Purpose.** A pre-registered, ground-truth-anchored comparison of BrainSafe AI against
general-purpose large language models (LLMs) on the exact task BrainSafe performs: predicting
CNS-relevant properties of small molecules from structure. The prompt, compound panel, and
scoring rubric below are fixed *before* any LLM is run, so the comparison is objective and
reproducible. BrainSafe's answers and the ground-truth key are frozen in
`BS_llm_benchmark_groundtruth.json`.

**Why this design.** We cannot call third-party LLM APIs from the analysis environment (no keys;
login-free endpoints are not programmatically accessible). The scientifically clean alternative
is a fixed-prompt human-in-the-loop protocol: the same prompt is issued to each named LLM, the
raw responses are pasted back verbatim, and every system — BrainSafe included — is scored against
the identical measured-data key by `BS_llm_score.py`. This avoids memorisation-contaminated
self-runs and makes the experiment repeatable by any reader.

## 2. THE PROMPT (paste verbatim into each LLM)

> You are a medicinal-chemistry assistant. For each compound below, predict its central-nervous-
> system profile **from its chemistry**. For **every** compound return a row with EXACTLY these
> fields, and do not omit any:
>
> 1. **BBB**: will it cross the blood–brain barrier? Answer `yes` or `no`, then a probability 0–1.
> 2. **hERG**: is it a clinically relevant hERG (cardiac) blocker? `yes`/`no`, then a probability 0–1.
> 3. **Primary CNS target**: the single main molecular target (e.g. AChE, MAO-B, SERT), or `none`.
> 4. **Measured potency at that target**: give a specific value (pChEMBL, or Ki/IC50 in nM).
> 5. **Nearest measured analogue**: the ChEMBL ID of the most similar compound that has a
>    *measured* value for that target, and that measured value.
> 6. **Confidence**: 0–1, and one line on how sure you are.
>
> Compounds: Donepezil; Galantamine; Rivastigmine; Rasagiline; Selegiline; Fluoxetine;
> Terfenadine; Astemizole; Quercetin; and this novel compound given only as SMILES
> `O=C1CCc2ccccc2N1CCN1CCN(c2ccccc2)CC1` (no common name).
>
> Return the answer as a Markdown table with one row per compound and the six fields as columns.
> Do not add caveats in place of values — always give your best numeric estimate for fields 2, 4,
> and 5.

*(Field 5 deliberately asks for a specific ChEMBL ID + measured value: this is verifiable and is
the key probe for confident hallucination vs grounded provenance.)*

## 4. Scoring rubric (applied identically to every system, incl. BrainSafe)

| Dimension | How scored (objective) |
|---|---|
| **BBB accuracy** | correct `yes/no` vs the frozen key (7 scored compounds) |
| **hERG accuracy** | correct `yes/no` vs the key (4 uncontested compounds: Donepezil+, Terfenadine+, Astemizole+, Galantamine−, Rivastigmine−, Quercetin−) |
| **Primary-target accuracy** | exact target match vs the key (6 compounds with a defined panel target) |
| **Calibration** | Brier score of the stated probabilities vs the binary key (lower is better) |
| **Provenance validity** | does the cited ChEMBL ID exist *and* carry a measured value near the one stated? (checked against ChEMBL) — a fabricated ID/value counts as a hallucination |
| **Hallucination rate** | fraction of rows with a fabricated ChEMBL ID or an unverifiable precise pChEMBL |
| **Honest uncertainty (novel compound)** | on the unpublished SMILES: does the system flag uncertainty (good) or assert a confident specific target/pChEMBL/ChEMBL ID that cannot exist (bad)? |

**Ground-truth provenance.** BBB / hERG / primary-target labels are uncontested approved-drug
pharmacology (drug labels + primary literature); only unambiguous items are scored (ambiguous
ones are marked null in the key). BrainSafe's own row is generated by
`predict_brain_profile()` and scored by the *same* rubric — it is not given any advantage.

---

## 5. Expected, testable contrast (hypotheses, to be confirmed by the scores)

- BrainSafe returns a **calibrated probability + conformal set + a real measured analogue with a
  real pChEMBL** for every compound, including the novel one (where it reports honest conformal
  uncertainty).
- General LLMs are expected to (i) give uncalibrated or missing probabilities, and (ii) on
  field 5, either refuse (losing the requested value) or **confabulate** a ChEMBL ID / pChEMBL —
  measurable as a non-zero hallucination rate — most visibly on the novel compound.

The manuscript will report whatever the scores actually show, including any case where an LLM
performs well.
